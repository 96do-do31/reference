## SCR-G09 찜한 방 `/guest/my/favorite-room` ✅

카드 그리드 + 페이지네이션. 카드 = **[찜하기] 토글** · `{구} {동}의 {건물유형}` · 방 이름 · `방N 화장실N 주방N (거실N)` · **총액원/1주** · `임대료 X원 관리비 Y원` · 할인 배지(`장기계약~N%할인`, `즉시입주~N만 원할인`)

## SCR-G10 최근 본 방 `/guest/my/recent-room` ✅

찜한 방과 동일 카드 + **[삭제하기]** 액션 추가 (개별 제거).
관련 API: `GET /v1/use-auth/rooms/recent-views`, `POST …/rooms/recent/view`

## SCR-G11 후기 관리 `/guest/my/review` ✅

탭: `전체 / 작성가능 / 작성완료` · "후기 N개" · **[후기 수정/삭제 안내]**
액션: [상세 후기 작성하기] [후기 수정하기] [더보기]
빈 상태: "아직 작성한 후기가 없습니다" + [단기임대 찾아보기]
> 수정/삭제는 **고객센터 1:1 문의로만** 가능. 리뷰 공개 규칙 → `33m2/DOMAIN.md` §6.2

## SCR-G01 홈 `/guest/main`

1. **히어로** — "삼삼엠투에서 / 잠깐 살 집을 찾아보세요" + 검색바
   - 검색 입력: "지역, 지하철, 방 이름 등을 입력해 주세요"
   - 일정 선택: "일정을 선택해 주세요"
2. **매물유형 숏컷 캐러셀** — 오피스텔(인기 배지) / 아파트 / 원룸 / 투룸 / 쓰리룸+ …
   - 각 카드: 유형명 + 한 줄 설명 + 일러스트 + `>`
3. **지도 진입 배너** — "원하는 지역의 집을 지도로 찾아보세요" (보라 배경)
4. **최근 본 방** — 카드 리스트 + 찜 하트
5. **캠페인 영역** — 프로모션 배너 (CDN `campaign/` 이미지)

## SCR-G02 지도 검색 `/guest/search`

- **상단 필터바**: 검색어 / 일정 / [검색] / 상세필터(아이콘) / 방 개수 ▾ / 가격 ▾ / 건물유형 ▾ / [초기화]
- **좌측 패널**: 매물 카드 그리드(2열)
  - 카드 = 썸네일 + 찜하트 + (우수임대인 배지) + 제목 + 부제 + `방N 화장실N 주방N 거실N` + **총액/1주** + `임대료 X원  관리비 Y원` + 할인 배지 행
- **우측**: 네이버 지도 + 가격 마커, 패널 접기 `‹` 핸들
- **URL 상태 동기화**: `lat`, `lng`, `zoomLevel` → 공유·뒤로가기 가능
- 지도 이동 시 bbox로 `map/markers` + `map/rooms` 재조회

## SCR-G03 매물 상세 `/guest/room/{rid}`

⚠️ 목록에서 **새 탭**으로 열림. SEO 타이틀: `{구} {동} {유형} 단기임대 | {방이름} | 삼삼엠투`

레이아웃: 좌측 본문 + 우측 스티키 예약 카드

**우측 스티키 카드**
- 최소 계약 기간 N주 / 공유·찜 아이콘
- **총액원 / 1주** (강조) → `임대료 X원  관리비 Y원`
- 할인 행: `장기계약 ~N%` `즉시입주 ~N만 원` (펼치기)
- "이용 가능 날짜 확인해보기" 링크
- **[계약 시작하기]** CTA
- 기간 선택 후 → 견적 상세 + 입주일/퇴실일 표시로 확장

**본문 (탭: 방 정보 / 계약 정보 / 후기 / 임대인 정보)**
| 섹션 | 내용 |
|---|---|
| 갤러리 | 메인 + 썸네일 6 + prev/next, `N / M` 카운터, 우수임대인 뱃지 오버레이, 워터마크 |
| 구조 | 방/화장실/주방/거실 개수 |
| 건물 유형 및 면적 | 유형, 전용면적 `5평 (17m²)` |
| 엘리베이터 및 주차 | 있음/없음, 주차 가능/불가능 |
| 방 소개 | `description` |
| 위치 | 도로명/지번, **카카오 지도**, 인근 지하철역 칩 |
| 교통 | `transportation` |
| 기본 옵션 / 추가 옵션 | 아이콘 그리드, "옵션 N개 전체보기" |
| 방 이용 방법 | `usageGuide` |
| 추가 설명 | `additionalDescription` |
| 관리비 포함 항목 | 가스/수도/전기 포함 여부 |
| 관리비 안내 | `managementFeeDescription` |
| **계약 정보** | 임대료·장기할인표·즉시입주할인표·관리비·청소비·보증금(+에스크로 안내) |
| **후기** | 평점 + 태그 리뷰 칩(카운트) + 이용 후기 3건 + "후기 N개 전체보기" |
| **임대인 소개** | 본인인증 배지 · 이름 · 소개 · 평점 · 받은 후기 · 임대 경력 · [채팅하기] |
| **환불 규정** | 취소일/위약금 테이블 + 안내사항 5항목 |

**리뷰 표시 규칙**: 이름 마스킹(`강*나`, `*`), 연월만(`2025년 12월`), 5점 척도

## SCR-G04 계약 요청 `/guest/contract/request`

섹션: 방 정보(도로명·지번 각각 [복사]) → 임대기간 → 결제금액 → 환불규정(실제 날짜 전개) → 안내사항 → 계약 절차 안내 → **임대인에게 인사 메시지(0/500)**
하단 스티키 바: `N주 · 기간` + **[계약 요청하기]**

## SCR-G06 채팅 `/guest/chat`
2단 레이아웃 — 좌: 목록(전체보기 ▾ 필터 + **주소·방 이름 검색**), 우: 대화창
빈 상태: "진행 중인 채팅이 없습니다."
> 스레드가 **매물 단위**로 묶임 (방 이름으로 검색 가능)
