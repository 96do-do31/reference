# Airbnb GraphQL API 카탈로그 (APK 정적 분석) ★★

> 출처: 안드로이드 앱 `com.airbnb.android` dex 문자열에서 추출한 **Apollo GraphQL 오퍼레이션 이름**.
> **1,363개 오퍼레이션 (Query 751 · Mutation 612)** — 33m2의 REST 180메서드에 대응하는 Airbnb 전체 API 표면.
> 변수·응답 스키마는 로그인 웹의 `niobeClientData`에서 교차 확보 (부록). 원본: `_shared/captures/airbnb.graphql-operations.txt`

## 규약
- 엔드포인트: `POST/GET /api/v3/{OperationName}/{sha256PersistedQueryHash}`
- persisted query: 쿼리 본문 대신 오퍼레이션명+해시 전송 (해시는 배포마다 변동, 오퍼레이션명은 안정)
- 응답: `{ data: { ... }, errors: [...] }` — 대부분 `presentation.{section}` 또는 `viewer` / `node` 루트
- 변수는 오퍼레이션별 Input 타입 (dex에 `*Input` 다수: SearchInput, PriceInput, OrderInput, ChallengeUserInput …)
