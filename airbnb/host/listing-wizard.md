# Airbnb — 호스트 모드 역설계

> 관찰 계정에 **등록 숙소 0건**. 따라서 투데이/달력/리스팅 대시보드는 빈 상태이며,
> 호스트 입력 모델은 **리스팅 등록 위저드**를 통해 추출.

| 영역 | 경로 | 상태 |
|---|---|---|
| 호스팅 대시보드 | `/hosting` · 탭: **투데이 · 달력 · 리스팅 · 메시지** | ⚠️ 진입 시 「변경된 약관 및 정책」 **차단 모달** (동의/동의하지 않음). 실계정 법적 동의라 대리 처리하지 않음 |

| 등록 위저드 | `/become-a-host` → `/become-a-host/{listingId}/{step}` | ✅ 1~7단계 확보, 8단계(사진)에서 차단 |

## 등록 위저드 — 총 16단계, 3개 페이즈

URL 라우팅: `/become-a-host/{listingId}/{stepSlug}`
- **주소 입력 후 즉시 draft listingId 발급** → 이후 모든 단계가 해당 draft에 저장
- 진행 상황 표시: `진행 상황: 16단계 중 N단계` + 하단 3구간 프로그레스 바
- 상단 상시 액션: `[궁금하신 점이 있나요?]` `[저장 후 나가기]`
- ⚠️ **순차 완료 강제** — 미완료 단계 이후로 URL 직접 이동 시 마지막 미완료 단계로 리다이렉트

## ⛔ 확보하지 못한 것 (사진 5장 실물 업로드 필요)

- [ ] **요금 설정** — Airbnb **호스트 서비스 수수료율** 노출 (33m2 3.3%와 직접 비교할 핵심 수치)
- [ ] **할인 설정** — 주간/월간 할인, 신규 리스팅 프로모션
- [ ] **즉시 예약 vs 예약 요청** 설정
- [ ] 공개 범위(visibility) 설정
- [ ] 리스팅 제목/설명 글자 수 제약
- [ ] 법적 고지(legal) — 한국 숙박업 신고 관련

### 수수료에 대해 현재까지 확정된 것 / 추정

**확정 (게스트 측 관찰)**: 체크아웃 「요금 상세 내역」에 **서비스 수수료 항목이 없음**. 총액 = (1박 요금 × 박수) − 할인.
→ 게스트 서비스 수수료가 **1박 요금에 내재화**되어 있음.

**추정 (미검증)**: 이는 Airbnb의 **호스트 단독 부담 수수료(host-only fee)** 구조와 일치. 이 경우 호스트 수수료율이 33m2의 3.3%보다 **상당히 높을 가능성**이 큼.
⚠️ 정확한 요율은 위저드 `price` 단계 또는 실제 리스팅 보유 계정에서만 확인 가능. **숫자를 명세에 확정 기입하지 말 것.**
